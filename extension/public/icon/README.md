# Extension Icons

Place your extension icons in this directory:

- `16.png` - 16x16 pixels (toolbar icon)
- `32.png` - 32x32 pixels (Windows)
- `48.png` - 48x48 pixels (extension management)
- `128.png` - 128x128 pixels (Chrome Web Store)

## Icon Design Guidelines

- Use a shield or security-related symbol
- Primary color: Blue (#0ea5e9)
- Ensure icons are clear at all sizes
- Use transparent background (PNG)
- Follow Chrome Web Store guidelines

## Tools for Icon Creation

- Figma: https://figma.com
- Canva: https://canva.com
- GIMP: https://gimp.org
- Inkscape: https://inkscape.org
